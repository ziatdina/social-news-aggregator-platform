# Функциональные требования к mvp
## Аутентификация пользователя
1. Форма регистрации с полями: "Email" (валидация формата), "Имя пользователя", "Пароль" 
2. Форма входа с полями: "Email" и "Пароль"
3. Перенаправление на главную страницу после успешной авторизации

## Главная страница
1. Содержит ленту новостей, с постами пользователей
2. Содержит кнопку для создания поста
3. Содержит кнопку выхода из системы
4. Содержит поле для поиска по содержанию постов

## Создание и управление постами
1. Возможность создания текстовых постов через кнопку "Создать пост"
2. Отображение каждого поста с информацией: фото профиля, автор, дата и время публикации, содержание

## Взаимодействие с контентом
1. Возможность ставить/снимать лайки на постах
2. Отображать количества лайков для каждого поста

## Профиль пользователя
1. Отображение информации о текущем пользователе в боковой панели
2. Возможность выхода из системы

## Хранение данных
1. Сохранение данных в localStorage (пользователи, посты, лайки)


# Use Case: "Просмотр ленты новостей и взаимодействие с постами"

### Актор: Авторизованный пользователь

### Предусловия:
- Пользователь успешно авторизован в системе

### Основной поток:
1. Пользователь заходит на главную страницу
2. Система загружает ленту новостей из localStorage
3. Система отображает посты в хронологическом порядке (новые сверху)
4. Пользователь просматривает посты:
   - Видит аватар и имя автора
   - Видит дату и время публикации  
   - Читает содержание поста
5. Пользователь ставит лайк на одном из постов
6. Система обновляет счетчик лайков
7. Система сохраняет состояние лайка в localStorage
8. Пользователь использует поле поиска для фильтрации постов
9. Система отображает только посты, содержащие введенные ключевые слова

### Альтернативные потоки:
- Лента новостей пустая:
  1. Система показывает сообщение "Лента пуста"
  2. Пользователь может создать первый пост

- Поиск не дал результатов:
  1. Система показывает сообщение "Ничего не найдено"
