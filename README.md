# Описание проекта
Этот проект представляет собой библиотеку React компонентов и демонстрационное приложение (социальной платформы-агрегатора новостей), показывающее его использование. Проект разделен на:
social-app - демонстрационное приложение 
ui-library - библиотека переиспользуемых React компонентов

## Технологический стек
### Runtime зависимости
- React 19 - UI библиотека
- React Router DOM - клиентская маршрутизация
- TypeScript - статическая типизация
- Material-UI (MUI) - компонент Modal для модальных окон

### Dev зависимости
- Vite - сборщик и dev-сервер
- Jest + Testing Library - тестирование
- ESLint - линтинг кода
- CSS Modules - изолированные стили

### Предварительные требования
- Node.js 18+ 
- npm 9+

## Установка и запуск
1. Клонирование репозитория
git clone <repository-url>

2. Установка зависимостей и запуск
cd ui-library
npm install
npm build

cd ../social-app
npm install
npm run dev

3. Открытие в браузере
http://localhost:5173/ - главная страница платформы
http://localhost:5173/auth - страница авторизации (можно попасть, нажав на "Выйти")
