# Описание проекта
## Социальная платформа-агрегатор новостей
Этот проект представляет собой библиотеку React компонентов и демонстрационное приложение (социальной платформы-агрегатора новостей), показывающее его использование. Проект разделен на:
social-app - демонстрационное приложение
ui-library - библиотека переиспользуемых React компонентов

Возможности платформы:
- Аутентификация пользователей (регистрация/вход/гостевой доступ)
- Создание и публикация новостных постов с форматированием
- Лента новостей с возможностью лайков
- Поиск по постам

## Установка и запуск
1. Клонирование репозитория
git clone <repository-url>

2. Установка зависимостей и запуск
cd ui-library
npm install
npm build

cd ../social-app
npm install
npm run dev

3. Открытие в браузере
http://localhost:5173/ - главная страница платформы
http://localhost:5173/auth - страница авторизации ("Выйти")
